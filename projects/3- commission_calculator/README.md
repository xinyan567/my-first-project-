## Real Estate Sales Agent Commission Calculator
## Project Description
This program calculates the commission amount that a real estate agent receives from a property sale based on the property category and sale price. Users can select from six different real estate categories, each with a corresponding commission percentage rate.
## Features
Displays a clear table of real estate categories and their corresponding commission percentages  
Accepts user input for property category (1-6)  
Accepts user input for property sale price  
Calculates and displays the agent's commission amount  
Handles invalid category inputs gracefully  
Outputs results with two decimal places for currency formatting  
## Technical Details
Input Validation: The program checks if the entered category exists in the predefined dictionary  
Data Structure: Uses a dictionary to map category numbers to commission percentages  
Formatting: Commission output is formatted to two decimal places using Python's f-string formatting
